# Personal Cosmos 滚动导航与银河穿越优化设计

日期：2026-08-13

## 目标

修复项目航线顺序错误、快速滚轮跨站和星光鼠标难以控制的问题；把银河到恒星系从图层交叉淡化改成具有明确空间连续性的镜头穿越；在《佣书》和《附近未见》阅读页提供项目说明书 PDF。

本轮不发布、不部署，不新增大型视觉依赖。《苹果落下之前》的 TapTap 链接等正式地址提供后再接入。

## 航线与滚动模型

固定停靠顺序为：

`Observer → 佣书 01 → 苹果落下之前 02 → 附近未见 03`

连续旅程仍使用一个 0–1 的进度值，但滚轮输入不再直接无限制叠加浏览器原始 `deltaY`：

- 单次事件先归一化并限制最大进度增量，避免高分辨率触控板或带惯性的鼠标一次跨过一个项目。
- 项目中心是强制停靠点。首次滚入停靠区时吸附并锁定；用户释放滚动后再次向同一方向滚动，才离开当前项目。
- 反向滚动遵循相同规则，可以依次返回上一站。
- PageUp、PageDown、方向键与 Space 继续在相邻停靠点之间移动。
- 阅读层、作品目录和星图打开时不消费宇宙滚动输入。

滚动计算封装为纯函数，测试覆盖大 `deltaY`、连续小步输入、停靠锁和反向移动。

## 银河进入恒星系

采用真实镜头推进，不使用白屏切换或额外的 hyperspace 依赖。

银河阶段分为三个连续区间：

1. 发现：银河保持完整轮廓，镜头朝核心前进，旋臂持续放大。
2. 穿越：镜头进入盘面，近处旋臂和尘埃产生更快视差；银河核心亮度适度提升，但不覆盖文字安全区。
3. 抵达：旋臂从视野边缘退出，银河图层完全淡出；恒星系只从核心位置开始显现，不把银河保留成杂乱背景。

银河与恒星系共享一个叙事空间原点。摄像机目标在穿越期间始终锁定核心，避免现有目标点从 `z=-32` 突然跳向原点的换景感。场景权重保证银河主体退出后才完成恒星系显现，仅保留极短的核心交接重叠。

`prefers-reduced-motion` 下不播放旋臂掠过动画，直接使用发现、核心、恒星系三个稳定关键帧。

## 星光鼠标

桌面精细指针环境隐藏系统指针，并显示一个可准确点击的星核：

- 星核每次 `pointermove` 立即更新到原始 `clientX/clientY`，不做位置插值。
- 使用一个轻量 2D Canvas 保存 4–6 个历史点，绘制短弧形、逐渐衰减的星轨。
- pointermove 不调用 React state setter；交互目标状态只在进入或离开按钮、链接时改变。
- 按压时星核收缩，交互目标上轻微放大，但中心位置不偏移。
- 阅读层、粗指针设备、低质量档位与 reduced-motion 下关闭轨迹；移动端不渲染自定义鼠标。

不引入 React Bits Pro 或 Splash Cursor。实现借鉴 React Bits 的局部、可配置组件边界，但使用当前项目已有的 React、Canvas 和 CSS，避免增加第二套 WebGL 指针效果。

《苹果落下之前》本轮不显示说明书或 TapTap 占位按钮；正式链接到位后添加到现有 `links` 数组。

## 失败处理与性能

- PDF 仍以普通 `<a>` 链接呈现；资源不存在时测试直接失败，避免发布坏链接。
- 银河只调整现有粒子与相机，不新增 npm 依赖。
- 星轨 Canvas 使用固定点数和 DPR 上限，页面失焦或组件隐藏时停止绘制。
- 运行时低质量档位关闭星轨并继续降低银河粒子预算。

- 单元测试：项目顺序、滚轮最大步长、不可跨站、反向停靠、银河/恒星系权重、核心相机轨迹、PDF 文件存在。
