# Personal Cosmos 滚动宇宙与真实天体素材重构设计

日期：2026-08-12
状态：已确认，待实施计划

## 1. 目标与范围

本轮重构解决两个核心问题：当前程序化星球造型缺乏可信度，以及空间旅程过度依赖点击。网站改为由滚轮持续驱动的个人宇宙，并以合法来源的真实天体纹理和 NASA 探测器模型替代不成熟的程序化主体。

本轮包含：

- 连续滚动的启动页、北斗导航、银河穿越、恒星系与项目停靠；
- 三颗项目行星与一个观察者探测器；
- NASA／CC0／CC-BY 素材引入、归档和失败回退；
- 《苹果落下之前》阅读层人物展示重组；
- 桌面星光鼠标、移动端和 reduced-motion 降级；
- 相关状态、交互、性能与视觉测试。

本轮不包含：

- 发布或部署；
- 新增大型视觉依赖；
- 为所有项目制作与《苹果落下之前》等量的专属交互；
- 重新生成或改画现有人物面部；
- 把阅读正文自动绑定到滚动并强制打开。

## 2. 已确认的参考原则

### 2.1 滚动节奏

- 参考 AIx Origin 的星空层次、深度感和黑色负空间。
- 参考 GeekOnUp 的核心机制：滚动距离连续映射动画进度，而不是每次滚轮事件硬切一屏。
- 不复制 GeekOnUp 的“点击进入”门槛。用户从启动页第一次向下滚动即可开始旅程。

### 2.2 视觉素材

- 主体优先采用 NASA 官方素材或明确标注 CC0／CC-BY 的资产。
- 禁止使用来源不明的图片搜索结果和授权不清晰的第三方模型。
- NASA 素材遵守其 Images and Media Usage Guidelines，并在项目内标注 NASA 或 NASA/JPL-Caltech 来源。
- 外部素材清单集中记录在 `THIRD_PARTY_ASSETS.md`，包含来源链接、作者／机构、许可证、下载日期和本地修改方式。

官方参考：

- NASA 3D Resources：https://science.nasa.gov/3d-resources/
- Explorer 1：https://science.nasa.gov/mission/explorer-1/about/
- NASA Images and Media Usage Guidelines：https://www.nasa.gov/nasa-brand-center/images-and-media/

## 3. 空间旅程与滚动模型

### 3.1 总体路径

```text
启动页
  → 北斗导航星标
  → 驶向个人银河
  → 穿越彩色旋臂
  → 核心恒星系总览
  → Explorer 1 观察者号
  → 苹果落下之前
  → 佣书
  → 附近未见
```

### 3.2 时间线区间

- 0–12%：启动页、星点建立、北斗连线与方向提示；
- 12–36%：驶向并穿越个人银河；
- 36–50%：离开旋臂并建立恒星系全景；
- 50–60%：停靠 Explorer 1“观察者号”，完成简短自我介绍与航行说明；
- 60–100%：依次停靠《苹果落下之前》《佣书》《附近未见》。

区间是实现初值，视觉调试时允许在不改变顺序和行为的前提下微调边界。

### 3.3 滚动行为

- 滚轮、触控板和移动端纵向滑动累计到统一的 `scrollProgress`；
- 向上滚动完全反向播放；
- 银河阶段保持连续运动和轻微惯性；
- 观察者号与项目区域具有柔和磁性停靠，但不锁死滚动；
- 观察者号只说明接下来将通过星际旅行依次认识正在进行的项目，不提前显示后续天体名称、数量或完整路线；
- 停靠只展示当前站点；项目站不会自动打开阅读层；
- 点击、“进入项目”按钮或 Enter 打开阅读层；
- 作品目录始终可见，并允许直接跳到任意项目停靠点；
- 目录直接打开项目的能力保留，使求职与合作访客无需完成动画。

### 3.4 状态与历史

现有六阶段状态机继续负责业务状态：

- `intro`
- `deep-space`
- `galaxy-transit`
- `system`
- `planet-focus`
- `reading`

新增的连续时间线只负责镜头和视觉进度。状态机仍负责 URL、项目选择、返回快照和阅读层，禁止用滚动百分比替代业务状态。

Browser Back、Esc 和“返回宇宙”恢复进入项目前保存的 `scrollProgress`、相机位置与观察目标。历史适配层继续集中处理 URL 解析、`pushState` 和 `popstate`。

## 4. 项目天体映射

### 4.1 《苹果落下之前》

- 使用正常圆形的灰蓝、土褐和冷白岩质天体；
- 删除苹果形凹陷和扁平顶部；
- 避免地球式蓝绿大陆和高亮云海；
- 1666 与 1696 以两条细轨道表现，靠近后才清晰；
- 删除当前容易被误解成月球的不明绕行小球；
- 停靠文案用中文说明双时间线、历史叙事和玩家行为，不使用抽象宇宙隐喻。

### 4.2 《佣书》

- 使用暗赭、灰金和煤黑色的真实岩质天体纹理；
- 外围设置稀疏的纸页、契约、渡口账册和地方志地图碎片；
- 纸页环不是连续土星环，远看只形成不规则轮廓；
- 靠近后才能辨认墨迹、红印和被划去的文字；
- 内容依据项目手册，强调材料的保存、标记、出售和毁弃，以及相互矛盾的史料。

### 4.3 《附近未见》

- 使用冷白、淡紫和珍珠灰的冰质天体；
- 外围使用低亮度透明球壳表示“五百米观察范围”；
- 靠近后显示手、耳朵、脚步、手机、照片和声音等具体观察方式；
- 文案围绕“从最初五百米重新认识附近”和记录具体发现，不使用“手机正在读的东西”等玄学描述。

### 4.4 Explorer 1“观察者号”

- “观察者”不再是行星；
- 使用 NASA 官方 Explorer 1 GLB，来源标注 NASA/JPL-Caltech；
- 探测器是进入项目区域后的第一站，位于三颗项目行星之前；
- 它承担网站引言和航行说明，而不是独立项目或旅程终点；
- 内容只用一个标题和两至三句短句介绍创作者、接下来的浏览方式，以及后方是正在进行的项目；
- 不提前列出后续项目名称、天体数量或完整路线，让访客继续滚动时逐步发现新内容；
- 联系方式与较完整的个人介绍留在常驻目录或独立信息入口，不堆叠在观察者号停靠画面；
- 不虚构 UFO 世界观，也不把网站说明写成宇宙设定。

## 5. 星光鼠标

采用已确认的 C 方案“轨道星标”：

- 中心为清晰的小星点；
- 外围是一圈低透明度、缓慢旋转的细轨道；
- 普通移动不产生长拖尾或粒子喷射；
- 悬停可交互对象时轨道轻微展开，中心亮度提高；
- 按下时轨道向内收束，松开后恢复；
- 星光鼠标只在 `(hover: hover) and (pointer: fine)` 的空间层启用；
- 阅读层恢复系统指针；
- 触屏设备不渲染自定义鼠标；
- reduced-motion 下停止轨道旋转并使用静态系统指针或静态小星点；
- 自定义指针不能成为唯一交互提示，所有按钮仍保留可见焦点和语义。

## 6. 《苹果落下之前》阅读层

### 6.1 阅读结构

- 阅读层使用近乎不透明的深色 2D 表面；
- 打开阅读层后隐藏当前星球的 3D 标题、轨道年份和高亮粒子；
- 内容按“作品是什么—玩家做什么—设计重点—人物与时代—开发资料”组织；
- 中文 UI 与正文使用思源黑体类系统链，历史内容和项目标题使用思源宋体类字体链。

### 6.2 人物图片顺序

- 第一张主视觉固定使用现有 `牛顿立绘.png`，即青年牛顿；
- 1696 年牛顿只在正文讲到三十年后的调查和铸币局时出现；
- 删除当前逐张向下排列 NPC 立绘的画廊。

### 6.3 NPC 群像

- 使用现有透明底 NPC 立绘制作宽幅油画群像；
- 所有现有 NPC 均进入群像；
- 人物面部直接使用原图，不由生成模型重画；
- 通过前、中、后三层站位保证每张脸不被遮挡；
- 统一暗色油画背景、地面接触阴影、边缘光和整体色调；
- 桌面端显示宽幅全景；
- 移动端提供可横向查看的画卷，不把所有人物压缩到一屏；
- 群像属于确定性图像合成任务，允许调整尺寸、位置、遮罩、色调和光影，不允许改变五官与角色身份。

## 7. 资产加载与性能

### 7.1 渲染方式

- 星球主体继续使用低成本球体网格；
- 真实感来自颜色、法线和粗糙度纹理，而不是高面数完整星球模型；
- 纸页环、年份轨道和五百米球壳是独立渲染层，不改变星球几何轮廓；
- Explorer 1 使用官方 GLB，只进行网页压缩、材质适配和合理缩放，不改变基本结构。

### 7.2 分阶段加载

- 首屏只加载深空和北斗所需资源；
- 进入银河前预加载银河纹理；
- 到达恒星系前预加载三颗行星的中等分辨率纹理；
- Explorer 1 在银河后半段后台预加载，确保它作为项目区第一站及时出现；
- 阅读层图片在项目停靠或目录悬停／聚焦时预加载；
- 纹理和 GLB 单独缓存，生产 JS gzip 仍不得超过 350 KB。

### 7.3 运行时质量

`activeBudget` 由设备档位和运行时性能档位共同计算，并真实控制：

- 星点与星云粒子数量；
- 星球纹理分辨率；
- 透明球壳与纸页数量；
- 轨迹采样；
- DPR；
- 后处理和近景尘埃。

移动端禁用近景尘埃、星光鼠标和高成本透明叠层，但保留完整空间层级与滚动停靠。

### 7.4 失败回退

- 星球纹理失败：显示同色系基础球体和项目名称；
- Explorer 1 失败：显示轻量探测器剪影；
- WebGL 不可用：显示 2D 项目目录；
- 任何视觉资产失败都不能阻塞目录、项目打开、URL 深链或阅读层。

## 8. 可访问性与输入

- 键盘方向键和 Page Up／Page Down 驱动同一进度；
- Space 向前推进一个停靠区间，Shift+Space 向后；
- Enter 打开当前项目；
- Esc 按层级返回；
- 语义按钮保留可见焦点环；
- `prefers-reduced-motion` 把长距离飞行改为短淡入淡出，并缩短磁吸时间；
- 移动端不依赖 hover 或双击；
- 作品目录在所有阶段可操作。

## 9. 组件和数据边界

- `ScrollJourney`：采集滚轮、触控板、触屏和键盘输入，输出归一化 `scrollProgress`；
- `JourneyTimeline`：把进度映射到阶段、相机目标和场景权重；
- `ProjectStops`：维护项目停靠点、磁吸范围和当前项目；
- `SceneCamera`：只消费统一相机目标，不自行读取 DOM 滚动；
- `CelestialAsset`：负责真实纹理／GLB 的加载状态与回退；
- `OrbitStarCursor`：独立管理桌面空间层的星光鼠标；
- `HistoryAdapter`：集中管理 URL、pushState、popstate 和返回快照；
- `Reader`：只消费项目内容，不渲染空间层重复标签；
- `activeBudget`：是 Scene 的唯一最终预算输入。

项目 `world` 数据扩展但保持可序列化，增加或明确：

- `assetType`
- `assetSource`
- `textureSet` 或 `modelUrl`
- `license`
- `fallbackStyle`
- `stopProgress`
- `entryCamera`
- `features`

## 12. 明确决策

- 采用“连续旅程 + 项目磁性停靠”，不采用全程硬切屏；
- 继续滚动只介绍下一个项目，不自动打开正文；
- 《苹果》使用正常球体并删除不明卫星；
- “观察者”使用 NASA Explorer 1，不使用行星或 UFO；
- 观察者号是项目区第一站，以极短自我介绍和航行说明激发继续滚动的好奇心；
- 观察者号不提前公开后续项目名称、数量或完整路线；
- 鼠标使用 C 型轨道星标；
- NPC 群像保留原始面部，禁止生成式重画；
- 外部素材以授权清晰和网页性能为第一约束；
- 本轮不发布、不部署。
